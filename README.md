# AddressStrip

Библиотека эффектов для адресной светодиодной ленты WS2812B.

## Цветомузыка

Библиотека не обрабатывает звук сама. Основное приложение считает спектр и раз в кадр передаёт **8 уровней октавных полос**:

```c
void AddressStrip_UpdateColorMusicBands(AddressStrip_st* strip, const float* bands); // 8 значений
```

### Что означают значения

| | |
|---|---|
| Тип | `float`, диапазон **0..1** (значения вне диапазона обрезаются) |
| 0 | тишина / уровень шума в этой полосе |
| 1 | самый громкий уровень этой полосы за последние секунды |
| Шкала | логарифмическая (дБ), нормированная **отдельно для каждой полосы** (АРУ) |
| Частота обновления | один вызов на кадр анализа, ~20–60 кадров/с |
| Сглаживание | **не нужно**: передавайте мгновенные значения кадра. Огибающую и детектор ударов библиотека считает сама |

Полосы (октавы):

| № | Частоты, Гц | Что там звучит |
|---|---|---|
| 0 | 40–80 | sub-bass, «тело» бочки |
| 1 | 80–160 | бас, бас-гитара |
| 2 | 160–320 | нижняя середина |
| 3 | 320–640 | середина |
| 4 | 640–1280 | середина |
| 5 | 1280–2560 | верхняя середина: вокал, малый барабан |
| 6 | 2560–5120 | присутствие |
| 7 | 5120–8000 | верха, хай-хэт |

Эффекты используют группы полос: низ = 0–1, середина = 2–4, верх = 5–7.

### Как считать полосы в приложении

Готовая реализация лежит в [examples/AudioBands.c](examples/AudioBands.c) (использует [FFT](https://github.com/krllplotnikov-libraries/FFT)). Цепочка обработки:

1. **I2S-микрофон → float −1..1.** У INMP441 24-битный отсчёт выровнен влево в 32-битном слоте: `(raw32 >> 8) / 8388608.0f`.
2. **Блок N = 512 отсчётов при fs = 16 кГц.** Получается 31.25 Гц на бин и кадр 32 мс (~31 кадр/с).
3. **Удаление постоянной составляющей**: вычесть среднее по блоку.
4. **Окно Ханна**: без него громкий бас «растекается» по всем полосам.
5. **Прямое БПФ** (`FT_DIRECT`) и мощности бинов `re² + im²` (корень брать не нужно).
6. **Сумма мощностей бинов в каждой октаве.** Для розового шума все октавы тогда получаются примерно одинаковыми.
7. **Перевод в дБ**: `10·log10(power)`. Масштаб `4/N` даёт 0 дБFS для полноразмерного синуса.
8. **Нормировка по каждой полосе.** Пик быстро растёт и медленно спадает, «пол» следит за ~10-м процентилем уровня. Значение полосы = `(dB − пол) / max(пик − пол, 30 дБ)`. Минимальный диапазон 30 дБ не даёт шуму растянуться на всю шкалу. Полосы ниже −90 дБFS считаются тишиной.

```c
static AudioBands_st audio;
static float samples[AUDIO_BANDS_FFT_SIZE];
static volatile uint8_t samplesReady;

// инициализация
AudioBands_Init(&audio, 16000.0f);

// колбэк DMA I2S (половина/полный буфер): переложить N отсчётов в samples[] и выставить samplesReady = 1

// главный цикл
while(1){
	if(samplesReady){
		float bands[AUDIO_BANDS_COUNT];
		AudioBands_Process(&audio, samples, bands);
		samplesReady = 0;
		AddressStrip_UpdateColorMusicBands(&strip, bands);
	}
	AddressStrip_Run(&strip);
}
```

`AddressStrip_UpdateColorMusicBands` вызывайте из того же контекста, что и `AddressStrip_Run`: главного цикла или той же задачи RTOS, но не из прерывания.

Если fs другая, границы полос пересчитываются в `AudioBands_Init`. Верхняя граница не может превышать fs/2. При fs = 44.1/48 кГц берите N = 1024–2048, иначе на басовые полосы придётся меньше одного бина.

### Настройка

Параметры детектора ударов (`ADDRESS_STRIP_COLOR_MUSIC_*` в `AddressStrip.h`) и нормировки (`AUDIO_BANDS_*` в `AudioBands.h`) можно переопределить при сборке через `-D...`. Основные:

- `ADDRESS_STRIP_COLOR_MUSIC_BEAT_MIN` (0.4): минимальный уровень огибающей для удара. Больше — меньше ложных срабатываний на шуме, но тихие удары пропускаются.
- `AUDIO_BANDS_MIN_RANGE_DB` (30): то же со стороны приложения. Чем больше, тем сильнее подавляется фоновый шум.
